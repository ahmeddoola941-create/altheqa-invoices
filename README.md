# altheqa-invoices
نظام إدارة فواتير الثقة للتشطيبات والمقاولات

## التشغيل
```
npm install
npm run dev      # للتجربة
npm run build    # للبناء
```

## المراحل
- [x] المرحلة 1: تجهيز المشروع (React + Vite، RTL، الهوية السوداء والذهبية، شاشة الموبايل)
- [x] المرحلة 2: حفظ الفواتير على الجهاز (رقم تلقائي متسلسل، تاريخ تلقائي، بحث، تعديل، حذف، نسخة احتياطية)
- [x] المرحلة 3: شاشة فاتورة جديدة (5 صفوف وزيادة لحد 50، حساب الإجماليات، حفظ)
- [x] المرحلة 4: الأرشيف (قائمة، بحث، فتح وتعديل، حذف بتأكيد)
- [x] المرحلة 5: تصدير الفاتورة صورة PNG عالية الجودة (تحميل ومشاركة)
- [x] المرحلة 6: أيقونات PNG للتثبيت، والعمل من غير إنترنت بعد أول فتح (Service Worker)

## النشر
المشروع موقع ثابت. بعد `npm run build` ارفع محتوى مجلد `dist` على أي استضافة ثابتة تدعم https.
مهم: الفواتير بتتحفظ في كل جهاز لوحده (localStorage)، فخد نسخة احتياطية من الإعدادات.
